# agent-guard

Deterministic static guardrails for repositories maintained with coding agents.

`agent-guard` inventories agent-facing repository surfaces and evaluates
reviewed static policy without executing agents, tools, skills, or MCP servers.
It produces sanitized evidence for CI and maintainer review.

Install with `python -m pip install yui-agent-guard`.

For current setup, GitHub Actions integration, and release information, see the
[GitHub README](https://github.com/yui-stingray/agent-guard#readme) and
[release documentation](https://github.com/yui-stingray/agent-guard/blob/master/docs/release-criteria.md).
